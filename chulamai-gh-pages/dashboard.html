      💬 Workflow A: Khách nhắn trực tiếp

      1. Hỏi info → 2. tour-advisor.mjs → 3. Tư vấn → 4. bao-gia.mjs → 5. Chờ cọc → 6. tour-calendar.mjs create
      BướcRô làm gìLoại
      1. Hỏi infoHỏi: số người, ngày, tuổi TEMANUAL
      2. Check tourtour-advisor.mjs --nl X --date YSCRIPT
      3. Tư vấnDựa output script, copy từ catalog.mdMANUAL
      4. Báo giábao-gia.mjs --json --send <thread>SCRIPT
      5. Chờ cọcKhách báo cọc → nhắn chú xác nhậnMANUAL
      6. Chốttour-calendar.mjs create --customer-threadALL-IN-1

      Bước 6 tự động: Calendar + nhóm Resort VH + xác nhận chú + xác nhận khách

      📨 Workflow B: Chú forward booking

      1. Đọc forward → 2. Check ngày+giá → 3. tour-calendar.mjs create

      Không có --customer-thread → chỉ gửi chú, không gửi khách

      ✏️ Sửa booking (sau khi chốt)

      tour-calendar.mjs find-update --name "Tên" --rooms/--adults/... --customer-thread <id>

      ✅ Sửa Calendar + gửi cập nhật chú + khách + nhóm

      ⛔ KHÔNG dùng create để sửa — create = thêm mới

      🔔 Escalate (hỏi chú)

      escalate.mjs → Chờ chú reply → resolve-escalation.mjs

      Khi: ngày blocked, tour ngoài catalog, customize, đoàn riêng, VAT, script lỗi
